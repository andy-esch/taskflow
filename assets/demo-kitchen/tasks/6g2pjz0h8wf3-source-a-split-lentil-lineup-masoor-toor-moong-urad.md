# Source a split-lentil lineup: masoor, toor, moong, urad

## Objective

Stock four lentils instead of one all-purpose bag, since each dal style leans
on a different one: red masoor for a fast weeknight dal that breaks down in
20 minutes with no soak, toor (split pigeon pea) for the everyday South Indian
pot, split urad for makhani's body, and moong for a lighter, faster-digesting
dal. Buy from a store with real turnover — rancid lentils smell faintly of
crayon and never soften right no matter how long they cook.

## Acceptance criteria

- [x] Masoor, toor, moong, and split urad each in a labeled, airtight container
- [x] Confirmed which need a soak (urad, chana dal) vs which don't (masoor, moong)
- [x] Smell/color check passed — no dusty or rancid lots

## Out of scope

- Whole urad or whole chana — that's the makhani and chana dal tasks' own call.
