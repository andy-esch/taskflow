# Research documentation ownership and portable agent routing

## Objective

Before replacing the contributor guidance, compare current primary-source documentation practices
with this repository's actual owners, drift checks, and agent entry points. Produce a bounded
research snapshot that informs the existing documentation Thread, not a new documentation platform.

## Acceptance criteria

- [x] A dated research record links primary sources for documentation
  ownership/progressive disclosure and Codex, Claude Code, Gemini CLI, and
  Antigravity instruction discovery/imports.
- [x] Current guidance and executable owners are inventoried; confirmed staleness is distinguished from historical motivation and unverified assumptions.
- [x] Recommendations explain shared AGENTS.md ownership, native Claude and
  Antigravity discovery, Gemini CLI differences, conflict handling, and limits
  without assuming identical agent loaders.
- [x] Small safe corrections are allocated to the ownership task; larger cleanup/checks are assigned to existing or new sequenced Thread tasks without duplicated scope.

## Boundaries

No product changes, new dependencies, agent settings changes, or architecture-policy decisions.
Research is evidence and a dated recommendation, not a new policy owner. The user has selected
AGENTS.md as the sole shared root guide, using native Claude and Antigravity discovery rather
than keeping CLAUDE.md or introducing GEMINI.md.
